## 這是什麼？
這是一篇**範例文章**，放在 Notion「文章庫」裡，狀態設為「待發布」。
### 你之後可以怎麼用
1. 用 Claude 寫好文章
2. 把文章標題、摘要、內文貼到這個資料庫
3. 把「狀態」設成 **待發布**
4. 每週五下午 3 點，Grok 會自動讀取這些文章
### Markdown 小提醒
文章本體建議用 Markdown 寫，之後轉到網站時會很方便。
```markdown
# 標題
## 小標題
- 列表
**粗體**
```
---
測試完成後，可以把這篇刪掉或改成「已發布」。
